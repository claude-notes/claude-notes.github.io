GPT-6.2 旗舰 Astra 来了，为什么我还是建议先用 Sol？｜ 附gpt最新升级订阅保姆级教程

就在北京时间 11 月 18 日 01:45，OpenAI 正式发布 GPT-6.2 Astra 和 Sol。不到半小时，两款模型就上了 OpenRouter。OpenClaw 在 03:47 确认接入。同一时间，各平台均快速上线这两款新模型。

GPT-6.1 Sol 发布刚过 49 天，6.2 Sol 就来了。Astra 隔了 75 天，上一代叫 GPT-6 Astra。那么这次的新模型跟以往的相比，有哪些主要加强呢？我们又该如何使用到GPT-6.2呢？

GPT-6.2 Sol 比 6.1 Sol 强在哪

让 GPT 整理会议纪要，摘要有了，发到群里之前还可能要补两句，谁负责，哪天交。可以把同一份会议记录和排期交给两代 Sol，让它们各出一份待办清单。哪版漏了负责人、截止时间或排期冲突，翻一下原记录就知道。

就我自己试过的任务，6.2 Sol 要返工的情况比 6.1 要少得多！！！

OpenAI 的内部评测 GDPval v2 考的是多步骤专业任务。GPT-6.2 Sol 比 GPT-6.1 Sol 高 5.3 分，标准 API 单价和上代一样。

GPT-6.2 Astra 这次更擅长照着模板出成品

做月报时，可以把上个月的 PPT、这个月的数据表和业务备注一起交给 Astra，让它沿用原来的布局、配色和字号，更新图表和结论。看下面的官方案例，原模板和两代 Astra 的结果摆在一起，页眉、插图和表格怎么排，一眼就能看出差别。

在同一套 GDPval v2 评测里，GPT-6.2 Astra 比 GPT-6 Astra 高 6.2 个百分点，输出 token 少 22%。另一项多步骤专业工作评测 Agents’ Last Exam 里，新 Astra 比上代高 5.2 分，评测任务成本不到上代的三分之一。做你自己的月报能省几轮修改，还得用手头那份文件试。

Codex 改代码，什么时候值得切 Astra

改个接口、按 PR 评审意见修一版，先用 6.2 Sol。把改动范围和要跑的测试一起交代清楚，看看它能不能把修改和测试结果一起交回来，省得你再问一句「测试跑了吗？」

如果列表翻页时偶尔重复，光看页面还不知道是前端重复发了请求，还是后端分页游标出了问题。这种要追到根因、修完还得补回归测试的活，值得试 6.2 Astra。OpenAI 收录的早期反馈提到，新 Astra 写的代码更简洁，测试更有针对性，来回修改的次数也更少。

Replit 拿两代 Sol 从零构建软件做过对比。6.2 Sol 的输出 Token 比 6.1 Sol 少 62%，速度接近上代 3 倍，还通过了更多测试。

平时改已有项目，更接近下面这组 FrontierCode 2.0。它拿真实代码库出题，按改动能不能达到维护者的合并标准来打分。这里比较的四款模型都设为 Max，费用按单次评测算。

Sol 从 39.0% 升到 43.8%，提高 4.8 个百分点，单次成本从 1.03 美元升到 1.29 美元。 Astra 从 42.8% 升到 44.2%，提高 1.4 个百分点，单次成本从 6.68 美元降到 5.97 美元。

两款 6.2 在这组题里只差 0.4 个百分点，Sol 的单次评测成本大约是 Astra 的五分之一。

GPT又可以开始接管执行任务啦！！

已经在付 Plus，这次还要升级吗？

已经有 Plus，打开 ChatGPT Work 或 Codex 就能选两款 6.2。 OpenAI 的发布公告也列了 Pro、Enterprise 和 Edu。Business 用户可以在 Work 里用，Enterprise 和 Edu 需要管理员先启用。

Plus 是 20 美元/月。Pro 有 100、200、500 美元/月三档，实际金额看结算页。如果是冲着 Ultrafast 极速模式去的，Pro 200 能给 Sol 开，Pro 500 两款都能开。Work 和 Codex 算同一份用量，平时老碰到上限，再考虑升档。

走 OpenAI API 用标准档，按每百万 token 计费。输入、缓存输入、输出三项，Astra 是 8 / 0.40 / 40 美元，Sol 是 2 / 0.10 / 10 美元。跟 GPT-6 Astra 比，新 Astra 的输入和输出单价各降 20%，缓存输入降 60%。Sol 沿用 GPT-6.1 Sol 的单价。走 OpenRouter 的话，按它的报价和路由计费。

GPT-6.2 订阅和开用，按这四步走

第 1 步，确认要升级的账号。 打开 ChatGPT 官网，登录你平时用的账号。以前买过会员的话，点头像 → Settings → Account，核对登录账号和套餐。如果你不知道如何升级订阅的话，可以看一下文末的升级订阅网站。

第 2 步，开通 Plus 或换档。 要开 Plus，在网页点头像 → Upgrade Plan（升级套餐）→ Get Plus。付款前核对套餐、金额和续费周期。已有 Plus 的直接看第 3 步。想换 Pro 档，到 Settings → My Plan 看有哪些档位，以及何时生效。

第 3 步，进 Work 或 Codex 切模型。 在 ChatGPT 切到 Work（工作） ，开个新任务。桌面端的模型控件在输入框下方。看到 Power 滑杆的话，点 Advanced → Model，选 6.2 Sol 或 6.2 Astra。Codex App 用模型选择器，CLI 输入 /model。

第 4 步，付了款却没看到模型，先别重复下单。 在设置里核对付费账号，再看当前开的是 Work 还是普通 Chat。用 iOS 或 Android App 买的，可以在 App 设置里点 Restore purchases（恢复购买）。团队账号找管理员核对模型权限。套餐还显示 Free，就联系 OpenAI 支持。
